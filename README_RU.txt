DEV | OXIDE 2.0

Новая версия:
- четыре вкладки: Show, Shoot, Memory, Settings;
- вращающийся значок компьютера вместо шлема;
- заголовок DEV | OXIDE;
- выбор цвета панели: белый, серый, фиолетовый, зелёный;
- экран активации с ключом DevNiko;
- перемещение и закрытие плавающей панели.

Важно: ключ DevNiko встроен в приложение и подходит только для демонстрации.
Это не серверная защита: ключ можно извлечь из APK. Не используй его как защиту
для платного доступа или секретных данных.

Вкладки пока демонстрационные. Приложение не внедряется в игры, не читает и
не изменяет игровую память и не обходит античит.
Сборка: GitHub Actions -> Build DEV Cheat APK.
